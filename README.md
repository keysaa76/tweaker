# LEVSCLOADES

Windows Debloater & Optimizer — prototype.

## Build online with GitHub Actions

1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Commit to the `main` branch.
4. Open **Actions** → **Build LEVSCLOADES**.
5. After the workflow completes, open the workflow run.
6. Download the artifact named **LEVSCLOADES-Windows**.
7. Inside the downloaded artifact is `LEVSCLOADES.exe`.

The current prototype does not apply system/GPU changes; its optimization buttons are placeholders for the next development stage.
